# Тропа — планировщик путешествий (версия 5)

Это учебный сайт по пункту 19: «Планировщик путешествий».

## Возможности

- Маршруты: создание, редактирование, копирование, поиск, удаление.
- Маршрут: остановки с датой, временем, стоимостью и координатами.
- Точки: поиск, добавление, показ на карте.
- Заметки, профиль.
- Сохранение в localStorage, импорт/экспорт JSON.
- Интерактивная карта: перетаскивание, масштаб, метки, линия маршрута.

## Как открыть

**Просто:** откройте `index.html` в Chrome или другом современном браузере.

**Если браузер блокирует сетевые ресурсы локальных файлов:** запустите сайт через `start_linux.sh` (для Linux) или `start_windows.bat` (для Windows), если на компьютере установлен Python 3. Можно вручную выполнить `python3 -m http.server 8765` в папке проекта, затем открыть http://127.0.0.1:8765/.

## Почему версия 5 отображает карту иначе

У старых версий при открытии как `file://` могли блокироваться библиотеки и картографические изображения. Версия 5 не загружает JS-библиотеки карт с внешних серверов и не использует WebGL-воркеры. Она загружает картографические изображения через стандартные HTML-теги `<img>`.

По очереди пробуются независимые источники изображения улиц: Esri World Street Map, OpenStreetMap France, HOT. Если все они недоступны, включается встроенная схематичная карта без улиц, с метками и линиями, а кнопка «Google Карты» открывает маршрут с остановками в полноценном картографическом сервисе.

Важное ограничение: **изображения реальных улиц не могут быть гарантированы без подключения к картографическому серверу**. Если нет доступа к интернету или в сети заблокированы все источники изображений, детальная онлайн-карта не появится. Для полной офлайн-карты улиц нужен заранее загруженный набор картографических данных, который не входит в компактный HTML-файл.

## Сохранённые маршруты

Если переходите со старой версии, сначала экспортируйте маршруты в JSON в «Профиль», затем импортируйте файл JSON в новой версии. localStorage может отличаться для разных файлов и адресов сайта.
